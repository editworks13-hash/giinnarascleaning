# Ginnara's Cleaning — Client Review Preview

**Status: Testing preview. This package is for client review only and is not a production deployment.**

## Run the preview locally

1. Install Node.js 22.5 or newer.
2. From this folder, run `npm start` or double-click `Start Website.bat` in the project source folder.
3. Open `http://localhost:3101` to view the site.
4. Create a customer account to walk through booking and sign-in/sign-out. Open `http://localhost:3101/admin.html` to review the admin experience. On the first server start, the terminal prints a temporary admin email and password.

This preview stores test accounts, booking information, and uploads locally in `data/`. Use sample information only during the client review. No live domain, external payment account, business contact details, or production hosting has been configured.

Please collect the client's design and content feedback before deciding on any production setup.
